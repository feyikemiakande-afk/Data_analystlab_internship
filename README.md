# Data Analytics Internship Portfolio

This repository contains projects completed during my Data Analytics Internship at AnalystLab Africa.

Over six weeks, I worked with real-world datasets using SQL and Python to perform:

- Data Cleaning
- Data Validation
- Exploratory Data Analysis (EDA)
- Data Visualization
- Insight Generation
- Business Reporting

## Projects

### Week 1: Online Retail Sales Analysis
- Python
- Pandas
- Matplotlib
- Seaborn

Key Insights:
- UK generated the highest revenue
- December recorded the highest sales
- Revenue was concentrated among a small group of customers

### Week 2: Netflix Content Analysis
- MySQL
- Python
- Pandas
- Matplotlib
- Seaborn

Key Insights:
- Movies account for approximately 70% of content
- Content additions peaked in 2019
- TV-MA is the most common rating

### Week 3: SQL Data Querying & Database Analysis**

Tools Used:
- MySQL

Key Insights:
- Retrieved business insights using joins, subqueries, and aggregate functions.
- Analysed customer, sales, and invoice data from a relational database.
- Improved SQL proficiency through real-world business queries.

### Week 4: Sales Dashboard & Business Intelligence**

Tools Used:
- Power BI
- Power Query
- DAX

Key Insights:
- Built an interactive sales dashboard to monitor KPIs.
- Analysed sales performance across regions, products, and customer segments.
- Used data visualisation to support business decision-making.

### Week 5: Business Analytics Case Study – Bank Marketing Dataset**

Tools Used:
- Python
- Pandas
- Matplotlib
- Seaborn

Key Insights:
- Previous campaign success was the strongest predictor of subscriptions.
- Customers aged 60+, students, and retirees had the highest subscription rates.
- Customer behaviour was a stronger predictor than account balance.
